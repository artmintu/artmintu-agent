# Artmintu

Binance Agent OS Mini Hackathon — Track A

Artmintu is an AI agent in VS Code using the official Binance MCP:
https://agent.binance.com/mcp/agentic

It fetches live BTCUSDT, then ALLOW or BLOCK. No live order. No withdraw.

## Rules
- Only BTC and ETH
- Max $50 per idea
- Spot only

## Demo
- BUY $40 BTC → ALLOW
- BUY $200 SOL → BLOCK
